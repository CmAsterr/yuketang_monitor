# 开发与验证

## 环境

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -c constraints-tested.txt -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
```

自动化测试均用临时配置、SQLite 和模拟外部接口。不得读取真实 config.toml 或 data/monitor.db，不得在测试中加入真实课堂或发送真实群消息。

## 浏览器检查

Windows 上安装 Edge 后执行：

```powershell
python tools/browser_qa.py
python tools/qq_browser_qa.py
python tools/desktop_browser_qa.py
```

脚本只操作临时本机服务。QQ 模拟发送不访问 QQ 平台；桌面专项使用短宽限加速检查，并单独核对正式 180 秒参数。截图与报告写入被忽略的 qa/。非 Windows 平台不声称这些 GUI 专项已通过。

## 构建

```powershell
python -m pip install build
python -m build
```

构建产物需检查 wheel 中的 static/、生命周期脚本和入口完整；安装包、用户数据、配置、原型和个人课件不得进入产物。

## 源码职责

| 文件 | 职责 |
| --- | --- |
| config.py / store.py | 配置、SQLite、迁移与课程记录 |
| protocol.py / runtime.py | 雨课堂协议、发现、连接、作答编排 |
| ai.py / presentation.py | 模型输出、Markdown 和数学呈现 |
| qq_client.py / qq_store.py / qq_service.py | QQ 网关、目标快照、投递与恢复 |
| web.py / static/ | 网页、API、实时更新 |
| lifecycle.py / desktop.py | 页面保活、正常退出和桌面启动 |

真实课堂／模型／QQ 的联调结果必须单独记录范围，不能把模拟接口成功等同于平台长期稳定可用。
