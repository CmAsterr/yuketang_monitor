# 从旧版升级到 v5

## 原 Selenium / PyQt 版本

1. 先停止旧程序，完整备份旧目录（包括 config.ini、courses、图片和日志）。
2. 在**另一个文件夹**解压 v5；不要把旧配置和驱动混进新目录。
3. 按 README 安装依赖、创建桌面快捷方式。
4. 在 v5 重新扫码登录，设置多模态模型并自检。旧 OCR/文本模型参数不会自动转换。
5. 课程由当前学生账号可访问的上课列表发现；手工添加规则不会替你加入雨课堂。
6. 需要 QQ 时，在正式设置保存自己的机器人凭据、绑定群，并给每门课程选群。

v5 不直接读取旧版 config.ini 或旧 courses 文件夹，也不会删除它们。旧记录继续用原程序或原文件查看；本版不提供旧题目历史的一键导入。

## 曾使用 Python + SQLite 的过渡版本

如果旧数据库有兼容的 `courses` 表，可在备份后显式执行课程迁移：

```powershell
python -m yktmon migrate-courses --legacy-db D:\backup\legacy.db --config D:\v5\config.toml --data-dir D:\v5\data
```

该命令只迁入课程及启用状态，不导入旧题目、旧通知或登录凭据。来源必须是已停止写入的数据库，或 SQLite backup API 生成的一致性快照；不要只复制正在运行的 WAL 主库。

## 已使用 v5 开发版

停止服务并备份 `config.toml` 和整个 `data/`。升级代码后仍使用相同路径启动，程序会执行幂等数据库迁移。新版本启动正常且核对记录后再保留或整理备份；不要删备份后才尝试迁移。

不要同时运行两份程序共享同一数据目录，也不要同时用旧试验网关和正式网关连接同一 QQ 机器人。

## 回退

停止新版本，在独立目录使用原版本和它升级前的备份。不要假定旧程序理解新版本数据库结构。发布分支保留 Git 历史，可从旧提交或旧标签取得旧程序。

## 旧仓库中的真实配置

旧版历史若曾提交 API Key、Webhook 或 Secret，删除最新文件并不能从历史移除它们。请到对应平台撤销或轮换旧凭据；v5 的空白配置示例不会复用旧值。
