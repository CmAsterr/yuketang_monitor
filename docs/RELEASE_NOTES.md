# 雨课堂习题看板 v5.0.0

v5 将旧版 Selenium/PyQt 监控重写为本机 WebSocket 课堂看板。无需 WebDriver 或 OCR，使用多模态模型直接理解题面图，不自动提交答案。

## 主要变化

- 课程与每节课堂独立管理，支持课堂标签、暂停／继续、改名和只读历史。
- QQ 官方机器人直连，群绑定持久化，每课程选择通知群，题目分阶段投递及未知结果保护。
- Markdown/数学公式解答、可信度和消息预览；原题保存在本机。
- Windows 桌面快捷方式，无终端窗口；最后一个看板页面关闭 3 分钟后正常退出。
- 命令行长期后台模式保留，配置和数据路径显式可选。

## 首次使用

下载并解压源码 ZIP，按 README 创建 Python 3.11+ 虚拟环境、安装依赖和生成桌面快捷方式。扫码账号必须已加入目标雨课堂课程。QQ 群绑定后，还需要给每门课程选群。

## 升级

先停止旧版并备份，在独立目录使用 v5。旧 config.ini、OCR 配置、WebDriver 和旧课程目录不直接兼容；请阅读 docs/升级到v5.md。不要把含凭据的配置或数据目录上传到仓库。
