# 桌面快捷方式与后台运行

## 第一次设置

需要 Windows、Python 3.11+ 和已安装的项目依赖。在项目根目录执行：

```powershell
python -m pip install -e .
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install_desktop_shortcut.ps1
```

该命令仅为本次 PowerShell 进程指定执行策略，不更改系统的永久执行策略。脚本使用当前 Python 对应的 `pythonw.exe` 创建桌面“雨课堂习题看板”快捷方式；不新增托盘程序，不添加开机启动项。

项目或 Python 移动后，重新执行安装脚本即可更新快捷方式。源码仓库保存生成脚本，不保存你电脑的 `.lnk` 或固定本机路径。

可选参数：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install_desktop_shortcut.ps1 `
  -PythonPath "C:\path\to\python.exe" `
  -ConfigPath "D:\example\config.toml" `
  -DataDirectory "D:\example\data" `
  -Port 8787
```

## 日常使用

1. 双击桌面快捷方式。
2. 如果同一配置、同一数据目录的服务已经在运行，直接打开它；否则后台启动新服务，确认就绪后打开默认浏览器。
3. 启动器和后台进程都不显示 CMD 窗口。重复双击不会重复启动服务或 QQ 网关。
4. 网页底部会显示当前运行模式，并有“退出程序”入口。

## 两种模式

| 模式 | 如何启动 | 关闭最后一个看板页面后的行为 |
| --- | --- | --- |
| 桌面模式 | 快捷方式启动了一个新服务 | 连接消失后宽限 3 分钟，期间重开可续用；之后停止所有监听和 QQ，再退出 |
| 长期后台模式 | `python -m yktmon serve` 或 `yktmon serve` | 关闭网页不退出；适合有意长期运行 |

如果快捷方式发现已有命令行服务，会复用它，**不会把长期后台模式强行改成桌面模式**。看页脚可以确认。需要切换模式时，先在网页正常退出旧服务，再双击快捷方式。

## 哪些操作会停止服务

- **切换到其他网页／最小化浏览器**：不作为关闭。独立 WebSocket 保活连接继续存在，不依赖模型配置读取成功。
- **多个看板页面**：只要还有一个连接就继续运行。
- **刷新页面**：新连接会接替旧连接，短暂断开有宽限期保护。
- **关闭全部看板页面**：桌面模式开始 180 秒宽限期，重新打开会取消倒计时。即使有课堂在监听，宽限期结束仍会退出，这是约定行为。
- **浏览器崩溃、冻结或网络断开**：连接失效后按同样规则处理；不能保证仅凭浏览器连接就准确区分“页面已关闭”和“页面被系统冻结”。连接检测还可能有短暂延迟。
- **电脑睡眠／唤醒**：不保证睡眠期间监听；唤醒后提供重新连接宽限，避免因为整段睡眠时间立刻退出。需要持续上课时保持电脑醒着。
- **“退出程序”**：确认后退出整个服务，所有课堂和其他看板页面都会断开。它不同于关闭某个课堂标签。

## 数据会不会丢？需要重绑 QQ 吗？

正常退出会取消运行任务、关闭 QQ 网关并关闭 SQLite；课程、题目、图片、QQ 群绑定和课程选群仍保留。下一次启动相同配置和数据目录，无需重绑群。

已开启的课堂监听意图会恢复。正在处理的题可恢复；发送期间中断的消息可能标为“结果未知”，核对群消息后再手动重试，不自动认定未发送。

关闭浏览器不会删除数据，换端口也不会删除数据。更换数据目录、删除数据库或换另一只 QQ 机器人则是不同情况，见 [使用教程](使用教程.md)。

## 失败时如何处理

- 启动错误会显示简短窗口，提示查看日志，不会闪过黑框后消失。
- 启动器日志：数据目录中的 `desktop-launcher.log`。
- 后台启动日志：`desktop-startup.log`。
- 业务日志：`yktmon.log`。
- 端口被其他应用、另一套数据或旧版服务占用时，启动器不会杀掉未知进程；先正常退出对应服务，或安装使用其他端口的快捷方式。
- 浏览器没有成功打开时，服务仍有有限启动宽限，可手动打开提示中的本机地址；无人连接时桌面模式会退出。
- 如果只是页面提示已退出，再次双击桌面快捷方式即可重新启动。

日志和数据目录不进入公开仓库。不要截图或发布明文模型 Key、QQ AppSecret 或真实登录信息。
