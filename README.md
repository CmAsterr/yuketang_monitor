# 雨课堂习题看板 v5

一个在本机运行的课堂习题工具：连接雨课堂学生端接口，使用 WebSocket 接收已推送习题，直接将题面图交给多模态模型解答，并可通过 QQ 群机器人通知。

**v5 是对旧版 Selenium / PyQt 程序的重写。**无需 WebDriver、OCR 或监控插件，不自动提交答案。

## 快速开始（Windows）

需要 Python 3.11 或更新版本。`constraints-tested.txt` 固定本次验证的依赖组合，减少安装环境差异。下载并解压 v5 源码包，在该目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -c constraints-tested.txt -e .
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\install_desktop_shortcut.ps1 -PythonPath .\.venv\Scripts\python.exe
```

以后双击桌面 **“雨课堂习题看板”**。启动器使用 `pythonw.exe`，不显示 CMD 窗口，不创建托盘图标；已有同一服务时直接打开它。

看板地址默认是 `http://127.0.0.1:8787/`。

1. **设置 → 雨课堂账号**：选择站点、保存、扫码。该学生账号必须已加入老师的目标课程。
2. **设置 → 多模态解答模型**：填写 API 地址和 Key，获取并选择支持图片的模型；保存后运行文字和图片自检。
3. **课程管理**：选择已有课程，点“新开一节”，然后开始监听。只是创建记录或打开标签不会开始收题。
4. **需要 QQ 时**：保存机器人凭据、连接、用绑定码确认通知群，再给**每门课程**单独选择通知群。

> 提前手工添加课程不会替你加入雨课堂。老师开课后，程序必须能从当前学生账号的上课列表发现它。进入课堂会调用签到接口，可能产生签到记录。

## 功能

- 课程与每节课堂记录分层管理；可改课程别名、课堂标题，使用独立标签查看或继续监听。
- 支持不同课程同时监听；同一课程同时只向一份本地记录收集。
- 已推送的新题先入库；图片和模型作答与 WebSocket 接收分开。
- 展示答案、Markdown 解析、MathML 数学公式及模型自评可信度；缺失自评明确标注，无法作答保留原因。
- 本地题面图可预览、下载；历史记录只读，查看不会补发通知。
- QQ 官方机器人支持持久化群绑定、课程多群选择、上课／下课通知、新题提醒、图片和解答。
- 已排队消息保留目标和内容快照；每群独立发送，按题目、目标、阶段及结果版本去重。
- 企业微信、钉钉、飞书保留独立配置；PushPlus 不在正式版中。

## 运行和退出

| 启动方式 | 关闭最后一个看板页面后 |
| --- | --- |
| 桌面快捷方式启动的新服务 | 宽限 3 分钟后正常退出，即使仍有课堂在监听 |
| 命令行长期后台模式 | 服务继续运行，直到你正常退出或停止进程 |

命令行方式：

```powershell
.\.venv\Scripts\python.exe -m yktmon serve
```

快捷方式发现已有命令行服务时会复用它，不强行改变退出规则。网页底部显示当前模式，并提供“退出程序”。后台标签、多个页面和刷新均有保活处理；浏览器被系统冻结或电脑睡眠时不能保证持续在线。

指定独立配置和数据：

```powershell
python -m yktmon serve --config D:\example\config.toml --data-dir D:\example\data --port 8788
```

默认配置是启动目录的 `config.toml`，默认数据在配置旁的 `data/`。一直使用同一套路径，重启后课程、登录态、QQ 群绑定和课程选群才会接续。

## QQ 通知

自己的 QQ 官方机器人直连，不要求同学注册其他平台，也不再调用一遍模型。

首次保存 AppID/AppSecret、加入目标群并允许主动发言、发送页面生成的绑定码，网页确认并命名后绑定即保存在本机。再在课程卡片点击“通知群”勾选目标。**测试消息能收到不等于所有课程都选好了通知群。**

每道题使用从本节 1 开始的题号：

1. 新题提醒：“新题提醒！”、课程与本节标题、中文题型、“大肥鱼正在做题喵～”。
2. 题面图片：优先使用 Markdown 公网原图链接和加粗标题。QQ 明确拒绝或没有链接时可降级为本地原生图片，日志注明标题未加粗。
3. 模型解答：答案、解析、可信度。原始平台题目 ID 不面向学生展示。

提醒不等待模型；但网络、图片转存、同群排队和平台限流仍会影响到达时间，不能保证零延迟。超时或发送中断会标记“结果未知”，不会盲目重发。请先核对群消息，再决定是否重试。

课程选群只影响之后首次收到的新题，不追溯补发旧题。改名不会改写已发或已排队的消息。查看历史记录不产生新投递。

## 已知边界

- 四个站点可配置，但当前真实使用证据主要来自长江雨课堂和一个指定 QQ 测试群；不宣称所有账号、群和客户端都已验证。
- 雨课堂接口和题目结构可能调整。发现课堂是定时查询，课堂内收题是 WebSocket；断线重试等待最多 5 秒，单次请求超时另计。
- 多模态模型的列表接口不能证明视觉能力，必须自检；自评可信度不是经过校准的正确率。
- 网页预览使用本地 Markdown/MathML，QQ 客户端排版可能不同。复杂公式、图片链接过期及平台权限仍可能导致发送或显示失败。
- 程序不会绕过账号权限、自动加入任意课程或代提交答案。请在有权限的课堂和通知群中使用。
- 长时间自然运行、其他 QQ 群以及非 Windows 桌面入口并未得到全面验证。

## 数据与公开仓库

`config.toml`、`data/`、归档、日志、图片、QQ 群标识、API Key/AppSecret、桌面 `.lnk` 和个人测试材料均不进入源码仓库或发行包。安装包和课件请自行从有权使用的来源取得。

QQ 消息只表示平台接口确认，不能替代实际收件核对。备份时先停止服务，或使用 SQLite 一致性备份；不要把含凭据的数据库公开上传。
